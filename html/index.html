MoMo Database Design & Implementation

Completed Dev

A normalized relational database system for processing Mobile Money SMS transaction data. Designed with 5 core tables (Users, Transactions, Transaction Categories, System Logs, and a junction table for M:N relationships), composite indexes for query performance, foreign key and check constraints for data integrity, and a full audit trail. Includes JSON schemas for API-ready response formats.

MySQL Database Design ERD Normalization SQL JSON Schema Audit Trail

MoMo REST API — Mobile Money Transaction System

Completed Dev

A full CRUD REST API for managing Mobile Money transaction records parsed from SMS XML data — built with pure Python, no frameworks. I handled the authentication and security layer (Basic Auth, authorization, endpoint protection). Includes a DSA performance comparison showing dictionary lookup is ~30x faster than linear search (O(1) vs O(n)).

Python REST API XML Parsing Basic Auth CRUD DSA No Frameworks
